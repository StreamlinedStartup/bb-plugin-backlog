# v0.2.0: Mention Backlog tasks in BB

You can now bring a Backlog task into a BB conversation without remembering its
ID. Type `@` and words from its title or description, then choose a result under
**Backlog tasks**. Search stays within the current project's selected source
and Backlog folder.

Suggestions show the task's title, ID, status, priority when set, and a short
description. Pause over a result for 1.5 seconds to see a larger preview before
choosing it. Keyboard selection works too, and pressing Command to prepare a
screenshot keeps the preview open.

![BB composer showing Backlog task suggestions and a larger task preview](https://raw.githubusercontent.com/StreamlinedStartup/bb-plugin-backlog/v0.2.0/docs/screenshots/task-mention-preview.png)

When you send the message, the plugin reads the task again so the agent gets
its current content. Completed and archived tasks are searchable, and saved
mentions still point to the task after a title change, filename change, or move
between task folders. The task ID and selected source must stay the same.

## Install

This release requires BB 0.43 or later with Plugin SDK **0.5.9 through 0.5.x**.
Update BB first if it reports an SDK mismatch.

```sh
bb plugin install 'git:https://github.com/StreamlinedStartup/bb-plugin-backlog.git@v0.2.0'
```

For contributors, dependency installation now uses pnpm with one checked-in
lockfile. Bun runs the tests and scripts.

## Verification and limits

All 86 tests pass, along with typecheck, SDK checks, and a clean production
install and build. Search, previews, keyboard selection, and task delivery were
checked in the live composer. Sending a saved mention after moving a task,
send-error/retry flows, and remote-host behavior still need live verification.

Type a word after `@` to see Backlog results. The larger preview currently
depends on BB's suggestion-row markup and may need an update if that UI changes.
