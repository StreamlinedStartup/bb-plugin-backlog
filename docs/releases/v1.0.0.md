# v1.0.0: A cleaner layout, documents, and decisions

This version rearranges the interface to make it cleaner and easier to use.
It also adds the documents and decisions of your Backlog.md projects.

## A cleaner layout that works in split view

![The task board with the new top bar](https://raw.githubusercontent.com/StreamlinedStartup/bb-plugin-backlog/v1.0.0/docs/screenshots/board.jpg)

All the navigation is now in one top bar:

- The project menu is at the left. The project list on the right side of the
  board is gone.
- The **Tasks**, **Documents**, and **Decisions** tabs are next to the project
  menu.
- **Folder settings** and **Refresh** are at the right. They work the same on
  every tab.

The task board now uses the full width. Documents and decisions use two panes:
the file list and the file.

The layout now follows the width of the plugin, not the width of the window.
This makes BB split view work better:

- When the plugin is narrow, the top bar wraps. The project name no longer
  overlaps the tabs.
- The file list moves above the file and becomes one row of small cards.
  Scroll the row sideways with the mouse wheel.
- Hide the file list with the panel icon in its header to give the file more
  space. Click the icon again to show the list.

## Documents and decisions

![A document with its front matter row and the file list](https://github.com/StreamlinedStartup/bb-plugin-backlog/releases/download/v1.0.0/documents.jpg)

The new **Documents** and **Decisions** tabs list the Markdown files in `docs/`
and `decisions/` of the Backlog folder.

- Each file card shows the start of the first paragraph, so you can find a
  file without opening it. Search also looks at this text.
- The front matter shows as one row of small items with icons: the ID, the
  dates, and the status. It no longer shows as a large heading.

![A decision with its status](https://raw.githubusercontent.com/StreamlinedStartup/bb-plugin-backlog/v1.0.0/docs/screenshots/decisions.jpg)

Click **Edit** to change a file. The editor wraps long lines. If the file
changes on disk while you edit, the plugin keeps your draft and shows the
current file.

![A decision in the editor](https://raw.githubusercontent.com/StreamlinedStartup/bb-plugin-backlog/v1.0.0/docs/screenshots/decisions-edit.jpg)

## Add selected text to chat

Select text in a task, a document, or a decision, and click the **+** button.
The text goes to the draft of the latest thread of the selected project. A
`Source:` line gives the path of the file. If the project has no thread, BB
opens a new thread draft for that project. The plugin never sends the message.

## Install

This version needs BB 0.43 or later with Plugin SDK 0.5.9 or a later 0.5
version.

```sh
bb plugin install 'git:https://github.com/StreamlinedStartup/bb-plugin-backlog.git@v1.0.0'
```

If the BB plugin store still shows an older version, use this command.

## Verification and limits

All 96 tests pass, with the typecheck, the SDK checks, and a clean production

decisions, front matter, editing, and file excerpts in the live BB app.
